# DayFlow 1.1

A local-first planner for Android: tasks with unlimited nested subtasks, habits with reminders, a full month calendar,
focus timer, evening review, insights, and two home screen widgets (Today and Habits).
All data stays on the phone (SharedPreferences). No internet permission.

Build: push to GitHub, open the Actions tab, download the "DayFlow" artifact (contains app-debug.apk).
